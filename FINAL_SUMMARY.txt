📝 如何使用 kernel-src 生成补丁
========================================

1. 进入目录：
   cd kernel-src

2. 查看当前状态：
   git log --oneline
   git show HEAD

3. 修改文件：
   vim fs/ext4/inode.c

4. 提交修改：
   git add fs/ext4/inode.c
   git commit -m "ext4: Your modification description"

5. 生成补丁：
   git format-patch -1 HEAD -o ../patches/

6. 查看生成的补丁：
   ls -lh ../patches/
